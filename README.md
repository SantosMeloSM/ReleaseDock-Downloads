# ReleaseDock Downloads

Distribuição pública dos **pacotes de instalação** dos projetos SantosMeloSM. O código-fonte de desenvolvimento permanece em repositórios privados.

## Como baixar

Abra a aba **[Releases](https://github.com/SantosMeloSM/ReleaseDock-Downloads/releases)**, selecione o projeto e a versão e escolha o arquivo compatível com o seu sistema. As versões aparecerão aqui somente depois de serem publicadas pelos pipelines oficiais.

| Projeto | Prefixo da versão | Arquivos planejados |
|---|---|---|
| NexoBlock | `nexoblock-vX.Y.Z` | `NexoBlock-vX.Y.Z.zip` (extensão de navegador) e SHA-256 |
| DiskVision | `diskvision-vX.Y.Z` | `DiskVision.exe`, `DiskVision_Setup_v0.4.exe` e SHA-256 |

Os checksums SHA-256 ajudam a verificar se o download está íntegro. Eles não são assinatura digital do desenvolvedor.

## Política de publicação

- **Somente binários ou pacotes finais revisados** devem ser anexados aos Releases.
- Este repositório não guarda senhas, segredos, chaves de autenticação nem configurações pessoais.
- Os pacotes não aparecem aqui automaticamente apenas por haver alterações de código. Exigem versão aprovada e pipeline de publicação concluído.
- Um ZIP de extensão de navegador contém os arquivos JavaScript executáveis da extensão. Eles podem ser inspecionados por quem fizer o download.
- Instaladores não são assinados digitalmente neste momento; verifique procedência e integridade antes de executá-los.

## ReleaseDock

O catálogo é mantido no [ReleaseDock](https://github.com/SantosMeloSM/ReleaseDock). Os lançamentos públicos deste repositório serão sincronizados com o site quando os aplicativos estiverem cadastrados e publicados e o workflow de sincronização concluir.

_A criação deste repositório não significa que já existam aplicativos publicados._
